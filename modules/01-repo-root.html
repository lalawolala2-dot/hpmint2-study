Repo 根目錄

根目錄幾乎沒有產品程式；它是 GitHub/Azure 與相依套件的入口。根 README.md 仍是 HP platform-repo 範本，不是 Mint 產品說明。

大綱

路徑內容
README.mdsample-platform-repo 範本（pipeline、CODEOWNERS、分支保護說明）。
.azurepipelines/ci.yml（X53Mint 主平台）、x53-release-prod.yml / x53-release-test.yml、find-blocked-versions.yml。
.github/CODEOWNERS、dependabot.yml。
gitman.yml外部套件來源與 lock revision；public / private group。
sonar-project.propertiesSonarQube 掃描設定。
var_map.yml建置/發佈變數對應。
.gitignore忽略 gitman checkout（HpCore、Amd…）、Build、Fixup Backup。

詳細解釋

gitman 會拉什麼

  • HpCore（public 用 HpCoreMirror，private 用 HpCoreFull）
  • HpAmd、Amd（AmdStrixHaloFP8FP11 → AGESA / CPM）
  • HpEpsc（Nuvoton SIO、USB-C）
  • HpFeature、HpFeaturePvt / HpFeaturePvtBins
  • HpWsCommonPkg（工作站共用，標了 HPQ-WKS）
  • ec-fw：註解寫明不參與 BIOS 編譯，給 Halo pipeline 的 EC 測試

CI 預設 gitmantarget: private。checkout 後這些目錄出現在 repo 根（已被 gitignore），PlatformPkg.dsc 用相對路徑 include 它們。

Azure Pipelines

ci.yml 繼承 bps-fw/templates 的 bios-ci-v2.yml，可覆寫 gitman 依賴、可跳過 Sonar。平台清單目前只列 X53Mint。
