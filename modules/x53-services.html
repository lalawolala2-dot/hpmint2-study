X53Mint HpPlatformServices 與 Library

HpPlatformServices protocol 的三階段實作，加上 Boot Manager 與 ACPI custom library。Core 問「這台機器有沒有 LID、電池、哪種網路」時走這裡。

大綱

INF階段
HpPlatformServices/Pei/HpPlatformPeiServices.infPEI
HpPlatformServices/Dxe/HpPlatformDxeServices.infDXE
HpPlatformServices/Smm/HpPlatformSmmServices.infSMM
Library/HpPlatformServices/*.inf（Base + Dxe lib）函式實作
Library/AcpiCustomLib/HpPlatformSmmAcpiCustomLib.infSMM ACPI 自訂
Library/PlatformBootManagerLibBDS / Boot Manager 平台行為

詳細解釋

Header 在 HpPlatformPkg/Include/Library/HpPlatformServicesLib.h。Fixup 曾改 Core 的 HpPlatformServicesProtocol.h（Wi-Fi 裝置類型字串）。若 Setup 或 Boot 順序「問平台能力」出現錯的，先核對這層回傳值與 ConDev PCD。
