Library

跨 SKU 的 platform hook：把 HpFeature / 晶片套件需要的 LibraryClass 接到這塊板上的實作。

大綱（INF）

Library角色
HpPlatformAudioInitLib / Cs3534HD Audio / Cirrus 初始化。
HpVerbTableLibCodec verb table。
HpFanConfigurationLib風扇表。
HpThermalPlatformHookBaseLib熱政策 hook（另有 X53 自己一份）。
HpSioVoltagePwrMonitorLib、PlatformSioInitPeiLib、PlatformNuvotonInitPeiLibSIO 電壓監控與 PEI 初始化。
SioCarbonFpCalculationTableLib碳／指紋相關 SIO 計算表。
SerialPortPlatformHook*（Desktop / Mobile / Mandolin CRB）序列埠 hook 多實作。
PlatformStage1HookLib / PlatformStage2HookLibAGESA 前後平台 hook。
HpPlatformPcdUpdateLib、BasePcdExportLib建置/執行期 PCD。
HpPlatformTablesLib裝置表（含 WWANTable.c）。
HpGNvsPlatformUpdateLibGlobal NVS 更新。
HpScriptLib、S3BootScriptTablePCI/MMIO script 與 S3 還原。
PlatformGraphicsConfiguration圖形組態。
PlatformRequestLib、PlatformDefaultSettingsSmmLib平台請求與 SMM 預設。
DxeHidI2cPlatformSupportLib、HpPlatformHidI2cTouchSupportLibHID I2C / 觸控。
ExternalUsbCustomStringLib外接 USB 顯示字串。
HpCpuInfoLib、HpVpinSelectionLibCPU 資訊、VPIN。
HpMobileWirelessUsbDetectHookLib、FusionDriverDefaultsLib無線 USB 偵測、Fusion 預設。

詳細解釋

EDK II 的 LibraryClass 在 DSC 指定「這個名字用哪份 INF」。HpFeature 宣告 hook 介面；本目錄給預設/共用實作。SKU 若要覆寫（例如 USB port、GPIO feature table），會放在 MultiProject/<SKU>/HpFeature/.../Library 或 MultiProject/.../Library，DSC 優先指到那裡。

HpScriptLib.c 內有平台 PCI command / IOMMU / SATA 等 script 表，並帶 S3 restore 旗標，是改 SSID 或早期 PCI 程式時會碰到的檔。
