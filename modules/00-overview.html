平台總覽

HpMint2 是 HP AMD 工作站 BIOS 的 platform 套件 repo，不是完整 EDK II 樹。本體在 HpPlatformPkg；晶片、核心、feature 由 gitman 在建置前拉到同層目錄。

大綱

  • 預設專案識別：PRJ_FAMILY_ID=X53、HP_PRJID=12453、HP_PRJ_PATH=Z2_MINI、HP_PROJECT_PATH=HpPlatformPkg/MultiProject/X53Mint（見 PlatformPkg.dsc，由 DefineMod.py 改寫）。
  • 三個 MultiProject SKU：X53Mint（Z2 Mini 工作站）、X89Chiron（MWS_A 筆電向）、W95MapleCRB（Maple CRB）。
  • CI（.azurepipelines/ci.yml）isMainPlatform: true 的平台是 X53Mint，hpPrep 參數 -p:X53。

詳細解釋

這個 repo 負責什麼

EDK II 平台層做三件事：選哪些共用模組進來（DSC include）、填板級表（GPIO/DXIO/APCB/ACPI）、hook 掉 HpFeature 需要的 platform library。真正的 Setup 框架、安全、網路堆疊在 HpCore；顯示/USB/熱的共用邏輯在 HpFeature；AGESA、CPM、FCH 在 Amd 套件。

啟動到 OS 的對應（精簡）

SMMHpPlatformSmmServices、Hotkey、AmdSioVwSmi、PlatformPrivateWMI、BiosUpdatePolicySmm、Vpin SMM

動態 Platform ID

HpPlatformPkg.dec 宣告 PcdHpPlatformID（僅限本 package 使用），以及工作站用的 PcdCpuCoolerType / PcdApuPower 等。APU 瓦數由 GPIO 板 ID 在 PEI 讀出後寫入 PCD，再餵 IRM / 風扇表。
