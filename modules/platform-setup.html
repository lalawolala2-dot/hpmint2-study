PlatformSetup

這塊板上的 Setup 題目、預設值與 Port Option；SMM 負責變數預設與 WMI。

大綱

  • PlatformSetup.qfr / PlatformSetup.hfr：主 Setup 表單片段。
  • PlatformSetupSmm.c + PlatformSetupSmmLib.inf、PlatformSetupDefaultsSmm.c、PlatformSetupWmiSmm.c。
  • PlatformSetupPortOption/：DXE + SMM + WMI + defaults，對應連接埠開關題目。

詳細解釋

HP Setup 不是單一 VFR 檔，而是 Core 的 Main.vfr 加上各 package 的 QFR include。本目錄是「平台自己的題目」；更多題目在 HpFeature（Boot/System/Port/Power）與 Fixup 覆寫的 Main.vfr。改預設值看 *DefaultsSmm.c；改 WMI 對應看 *WmiSmm.c。
