X53Mint BLD / EC / FUR / Binaries

不編譯成一般 C 模組、但會進 ROM 的東西：BiosId、flash 地圖、EC 版號、PD/Retimer 映像、Preboot Wi-Fi。

大綱

  • BLD/BiosId.env、BiosIdUpdate.env、LAYOUT32.RSP、BIOSImageDirectory32M_LPDDR5_FP11_Z2_MINI.xml
  • PreBuildPlatformConfig.bat、postbuild_options.yaml
  • EC/：HpEcFireBirdFwVersion.equ（FireBird EC 版號標頭）
  • FURBin/PD/：TI TPS66994 / 66993 / CastroU 的 PD 韌體 INF
  • FURBin/Retimer/PS8835/：PS8835 retimer
  • Binaries/PrebootWifi/：RZ6xx / RZ7xx / WCN685x launcher 與 WLAN INF
  • Binaries/AmdFmtc/：AMD FMTC 給 HP 的 README
  • SioConfigurationTable/：SIOCT CSV → SicotParse.py 產生 HpSuperIoSioct.inc（見 ReadMe.txt）

詳細解釋

FUR（Field Updatable Resource）讓 BIOS capsule 連 PD/Retimer 一起更新。INF 把 .bin 包進 FV。SIOCT 是 SuperIO 暫存器表的資料驅動流程：改 CSV 再跑 parser，不要手改產生出來的 inc。
