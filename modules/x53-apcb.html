X53Mint APCB

AGESA Platform Configuration Block：每種 DRAM 顆粒一個子目錄。基底板資料在 Z2_MINI，vendor 目錄多半只覆寫 SPD。

大綱

共用（APCB/Z2_MINI/）含 token、電壓、error out、eSPI、DP PHY、board-id 方法等 ApcbData_FP11_GID_* 檔。各 vendor 目錄有 SetApcbDataFileList.bat、ApcbCustomizedBoardDefinitions.h、ApcbData_FP11_GID_0x1704_Type_SpdInfo.c 與 SPD header。

目錄代表 SPD / 顆粒
Z2_MINI板級 APCB 主體（非單一顆粒）。
Z2_MINI_Samsung4 / 8 / 16Samsung LPDDR5 容量 SKU。
Z2_MINI_Samsung_E4 / E8 / E16Samsung 「E」系列顆粒（如 K3KL8L80EM / K3KL9L90EM / K3KLALA0EM）。
Z2_MINI_Hynix4 / 8 / 16Hynix 容量 SKU。
Z2_MINI_Hynix_C4 / C8 / C16Hynix 「C」系列。
Z2_MINI_Micron4 / 8 / 16Micron（如 MT62F*）。

詳細解釋

建置時 BLD/ApcbBuild.bat 依 BiosId / 專案選擇 file list，把對應 SPD 編進 PSP/AGESA 能吃的 APCB 映像。換顆粒 = 新目錄 + SPD header + 更新 bat 清單，而不是改 AGESA 核心。Fixup 裡也有一份 StrixHalo FP11 SPD header，給上游 AgesaPkg 補顆粒。
