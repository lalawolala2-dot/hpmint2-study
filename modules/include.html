Include

HpPlatformPkg 對外 header：Setup 頁面 ID、Protocol、Platform ID 與錯誤碼。DSC 的 [Includes] 也指向這裡。

大綱

檔案 / 目錄用途
Protocol/ActiveBiosProtocol.h、FlashDeviceInfo.h平台 protocol。
Library/HpPlatformServicesLib.h、BaseHpPlatformServicesLib.hServices library API。
Setup/*.h 與 .hfr / .qfrSetup 進階頁、Boot、Port、Security、System Info 的題目定義。
PlatformIdInfo.h、PlatformDefinitions.h板 ID 與編譯期平台巨集。
SioRegs.h、SioPlatformDefinitions.hNuvoton SIO。
ThermalDef.h、HpVpinSelection.h熱與 VPIN 選擇。
Guid/PlatformUndi.hUNDI driver GUID（與 DEC 中 gPlatformUndiDriverGuid 對應）。

詳細解釋

改 Setup 字串或題目可見性時，通常同時動 Include/Setup 的 header 與 PlatformSetup 的 VFR/QFR，以及 Fixup 裡 HpCore Setup 的 Main.vfr。Platform ID 則被 Library（例如 HpScriptLib）與 APCB board-id 方法共用。
