Fixup / Override

hpprep 在編譯前把 Override 檔複製到 gitman 套件上；hpcln 再還原。這是「不能直接改上游」時的補丁目錄。

大綱

  • Fixup/readme.txt、Fixup/Wks/readme.txt：流程與注意事項（改動要加 [HP_MOD_FIXUP]）。
  • Fixup/Override/：較通用的 Core/Feature/EDK 補丁。
  • Fixup/Wks/Override/：工作站（Wks）專用，量大。
  • Backup 目錄被 gitignore，是 prep 的備份。

詳細解釋

機制

預先建置（hpprep）把 Override 樹鏡射到 HpCore、HpFeature、Amd 等 checkout。所以你在那些套件裡看到的 diff，有可能來自這裡而不是上游 commit。讀碼時若上游檔「怎麼跟 GitHub 不一樣」，先搜 Fixup。

Wks Override 分類

Override 根典型改動
HpCoreSetup Main.vfr、USB/XHCI、Smbios、BootOrder F10、ErrorHandling、PublicWmi MOF、Absolute Persistence。
HpFeatureUSB port 外接政策、Gfx ACPI、BuiltInDevice 視訊記憶體、ConnectionDevice、Thermal PMF、Electronic Label、ErrorHandling CMOS 按鈕。
AmdAGESA NBIO STXH early init、APCB SPD header、CPM Maple addendum、FCH SMM。
HpAmdChipset PlatformStage2、VideoMemorySize、DASH/DMTF、TSME。
HpEpscNuvoton 324 SIO ASL/監控、USB-C UCSI、TI PD discovery。

根 Fixup/readme.txt 還列了歷史項目（PSP、CMOS 0x0B、SMM paging、UMA/DIS）。Wks readme 目前記了一筆：BCU 裡 Wi-Fi 裝置類型字串（EMBEDDED vs EXPANSION）。
