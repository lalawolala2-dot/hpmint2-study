X53Mint HpFeature

把共用 HpFeature 套件「打開哪些、hook 接到哪」寫成 DSC，並提供板級 Library。程式本體仍在 gitman 的 HpFeature。

大綱 — Config DSC

由 HpFeaturePlatformConfig.dsc 全部 include：

  • Misc / Boot / System / BuiltInDevice / Port / PowerManagement
  • UsbPort、ErrorHandling、HID、RTD3 ACPI、Diagnostic、Thermal、FirmwareFlash、Audio
  • Gfx：HpGfxMisc、Nvidia、AmdGraphics、Lid、Brightness、DreamColor、InstantOn、AmdPowerXpress、AddonGfxPolicy、AioGfxPolicy

Notebook 用 Lid/Brightness；Desktop 用 AddonGfx；AIO 用 AioGfx。Mint Mini 仍可能編進多份 policy，實際生效看 PCD。

大綱 — 板級 Library 目錄

路徑hook
HpUsbPortConfig/Library/HpPlatformUsbPortConfigLibUSB port 對應。
PortOptions/Library/HpStorageEnablePlatformHookPeiLib儲存啟用 PEI hook。
HpThermal/Library/HpThermalPlatformHookBaseLib熱 hook。
HpFeatureMisc/Library/HpGpioFeatureSupportTableLibGPIO feature 表。
HpHumanInterfaceDevices/.../ButtonIndicatorPlatformHookLib按鈕指示燈。
HpRtd3AcpiPlatform/.../HpRtd3AcpiPlatformUpdateLibRTD3 ACPI 更新。
HpGfx/*Addon/AIO boot priority、PCIe slot 定義、PowerXpress GPIO、亮度 EDID、OLED、Lid、DreamColor ROM WP、InstantOn TCON、GPU SSID、Post logo。

詳細解釋

學習時把「Config.dsc 的 TRUE/FALSE」和「Library 的表」當成兩層：前者決定鏈結哪個 INF，後者是這塊 PCB 的數字（哪個 GPIO 是 lid、哪個 PCIe slot 是 dGPU）。
