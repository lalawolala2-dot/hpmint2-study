HpMint2 模組清單

這份靜態站把 HpMint2（HP AMD 工作站 BIOS 的 platform 層）拆成 folder module：每頁一句話角色、大綱、再往下解釋。預設主專案是 X53Mint / Z2_MINI。

建議閱讀順序

  1. 平台總覽：這個 repo 在整棵 BIOS 樹裡站哪裡。
  2. 建置進口：PlatformPkg.dsc 如何把外部套件與本平台 glue 在一起。
  3. MultiProject 共用骨架，再進 CpmOverride 與 Config。
  4. 共用 ACPI / Library / 風扇功耗 等跨 SKU 程式。
  5. 最後看 X89Chiron、W95MapleCRB 與 X53 的差異。

A. 總覽與建置

平台總覽

X53 / 12453 / Z2_MINI；三個 SKU；gitman 依賴。

Repo 根目錄

CI、CODEOWNERS、gitman.yml、sonar。

建置進口

DSC / DEC / FDF / BLD 腳本。

B. HpPlatformPkg 共用 folder module

資料夾一句話
AcpiTables平台 DSDT/SSDT，依 Z2_MINI / MWS_A / CRB5 分板。
IncludeProtocol、Setup VFR header、Platform ID。
Library約 25 個 platform hook library。
PciPlatformDxePCI 平台回呼（Option ROM / 資源）。
FlashInfoFlash 區段與 NVRAM header 資訊。
BiosUpdatePlatformPolicyBIOS 更新政策（PEI + SMM）。
PlatformSetupSetup 題目、Port Option、WMI。
PlatformFormsSetup 表單 callback 註冊。
PlatformMudManufacturing Unique Data（MAC、dAMP…）。
PlatformPrivateWMI平台私有 WMI（SMM）。
HpIcicleIcicle 診斷/事件（PEI/DXE/SMM）。
HpSecureStorageDevice安全儲存裝置 PEI/DXE。
風扇與 APU 功耗HpZ2PerformacePei、PremiumFan、FanControlUpdate。
HpZ2AmdEccLinkZ2 AMD ECC 連結。
Hotkey熱鍵 SMM。
SmartCover機殼蓋偵測 porting / SMBIOS。
AlsCalibration環境光感測校正。
AmdSioVwSmiSIO 相關 SMI。
WiFiSupportAMD 平台 Wi-Fi 支援 DXE。
Fixuphpprep 覆寫 HpCore / Feature / AGESA。

C. MultiProject SKU

路徑角色
MultiProject/三 SKU 平行目錄；HpFeaturePlatformConfig.dsc 彙總 feature 開關。
X53Mint/Config本機 PCD 與平台 DEFINE（深讀）。
X53Mint/CpmOverrideOEM CPM 表：GPIO、DXIO、USB、RTD3。
X53Mint/APCBLPDDR5 APCB / vendor 變體表格。
X53Mint/HpFeaturefeature 開關與 gfx/usb/thermal hook。
X53Mint PlatformPorting*PEI / DXE / SMM 板級 porting。
X53Mint Services + LibraryHpPlatformServices 與板級 lib。
X53Mint BLD / EC / FUR / Binaries映像、EC、PD/Retimer、Preboot Wi-Fi。
X89ChironNotebook / MWS_A 差異大綱。
W95MapleCRBMaple CRB 差異大綱。

本文件不展開 gitman 拉進來的 HpCore / HpFeature / Amd 內部；那些套件不在本 repo 原始碼裡。
